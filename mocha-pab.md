# Abstract 

This specification defines how a set of devices owned by a common user can syncronize a personal address book that that maps identies to human readable names they trust. 

# Naming 

The Moq Tracks that carry address book contact cards are in a Namespace of:

mocha-v1-<Proivder>-<OrgID>-pab-<UserID>

The tracknsames are:

msg-<DevID>

There is one group per month. 

Each object is a card. 

The cards are roughly a rfc7095 jcard
