# Abstract 

This specfication defines how mutlit party audio video converences are set up. This supports both simulcast and scalable media codecs. 

# Naming Media 

mocha-v1-<Proivder>-<OrgID>-media-<TeamID>-<ChannelId>-<MeetingID>

The tracknsames are:

audio-<redition_id>-<DevID>

speaking-<redition_id>-<DevID>

video-<redition_id>-<DevID>


# Naming Catalogs 

mocha-v1-<Proivder>-<OrgID>-catalog-<TeamID>-<ChannelId>-<MeetingID>

The tracknsames are:

catalog-<DevID>

Catalogs describe what rendeitions exist and what they are.
